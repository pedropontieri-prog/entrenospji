# EntreNós: Seu Espaço Seguro

Prompt para Lovable — Plataforma de Apoio Emocional

Crie uma aplicação web completa de um MVP de uma plataforma digital de apoio emocional e acompanhamento psicológico, com foco em anonimato, acolhimento, privacidade, simplicidade e segurança. O nome da plataforma é EntreNós

A plataforma funciona como um ambiente intermediário entre usuários/pacientes e profissionais de saúde mental. O principal diferencial é permitir que o usuário utilize um apelido anônimo dentro da plataforma, reduzindo a sensação de exposição, vergonha ou medo de julgamento ao buscar ajuda.

1. Objetivo do produto

O objetivo é criar uma experiência digital simples e acolhedora para pessoas que desejam:

Organizar seus sentimentos;

Registrar seu estado emocional;

Manter um diário emocional;

Compartilhar determinados registros com um profissional;

Manter comunicação assíncrona com um profissional de saúde mental;

Buscar apoio sem precisar expor imediatamente sua identidade pessoal.

O produto não deve se apresentar como substituto da psicoterapia tradicional e não deve realizar diagnósticos automáticos.

O MVP deve validar principalmente estas ideias:

A possibilidade de buscar apoio emocional sem expor o nome real publicamente.

Registro organizado de emoções e sentimentos.

Criação de um diário emocional.

Comunicação privada e assíncrona entre usuário e profissional.

Uma experiência simples, segura e emocionalmente acolhedora.
